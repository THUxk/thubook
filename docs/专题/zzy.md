      - 5月28日24:00前院系审核课程认定申请
      - 5月29日13:00前注册中心进行最终审核

## 转专业条件（根据2024年转专业总结）
根据教育部有关规定，以下学生不得转专业：
   - 艺术、体育类专业学生不得转至普通类专业
   - 外国语中学推荐保送录取的学生不得转到非外语类专业
   - 强基计划录取的学生原则上不得转到录取专业之外的专业
   - 提前批（马克思主义理论、定向及单独代码批次）及非强基计划双学位专业录取的学生转专业需征得有关部门同意

   特殊培养要求的按相关规定执行。医学院临床医学八年制专业以及协和医学院与清华合作办学的临床医学八年制专业不接收非八年制转专业学生。

   各院系接收转专业计划和具体接收条件详见《2024年院系接收转专业学生计划》。详细情况请直接与相关院系联系。

   - 大一转出学生人数不超出专业基准数的15%
   - 大二转出学生人数不超出本年级专业人数的10%
   - 转专业学生只能申请一个专业
   - 跨学科大类转专业的学生有可能编入低一年级学习（俗称降转）

   转专业同学应慎重退课。根据《清华大学本科生学籍管理规定》，学生连续两个学期每学期取得学分少于6学分将予以退学处理。

## 转专业概况

   转专业是每年春天的一项重要活动。大类招生背景下，大一的转专业称为分流，分为一次分流（大类内分流）和二次分流（不限范围，全校除个别院系特殊规定）。

   转专业一般分为三个阶段：

   1. <span style = "font-weight:bold">申请阶段</span>：网上提交申请资料，包括个人信息、个人陈述、学习情况自评及各院系要求的材料。
   2. <span style = "font-weight:bold">初筛与面试</span>：初筛后发送面试信息，各院系自行设计面试内容。
   3. <span style = "font-weight:bold">录取阶段</span>：信息门户上查询录取结果，整个流程大约持续三到四周。

   转专业的核心考量点是学生进入院系后的适应能力、学习能力和综合素质。因此，转专业成功与否不仅取决于成绩，还包括面试表现和其他综合因素。

## 2023年转系情况

   - <span style = "font-weight:bold">转系名单发布时间</span>：5月16日上午9:29
     - 清华大学2023年转系于5月5日8:00开始报名，5月7日24:00截止，预计5月11日前完成面试，5月16日出转系名单。
   - 计算机系转系情况：
     - 大一：21/21（报名人数/计划接收人数）
     - 大二：15/18（报名人数/计划接收人数）
   - <span style = "font-weight:bold">GPA影响</span>：部分大二转计算机的小朋友GPA在原院系排名后50%，但计算机系未报满，所以转成的应该是多数。
   - <span style = "font-weight:bold">趋势</span>：信息匮乏情况下，选择转软院的学生较多，部分学生因担忧计算机系报录比而选择软院，结果软院报满，计算机系未报满。

## 强基计划影响

   - <span style = "font-weight:bold">实行时间</span>：2020年
   - <span style = "font-weight:bold">影响</span>：导致约1/4至1/3的本科生无法参与转专业
   - 录取人数变化：
     - 2021年春季，部分院系出现大一报不满、大二报超现象，录取人数大幅减少。
     - 2022年春季，大一大二的书院学生比例增加，报满情况减少，录取人数再降。
     - 2023年录取人数与2022年相比，转系人数稳定在180左右，而往前五年稳定在400出头。

## 问题与思考

   - 转系人数减少原因：
     - 强基计划只导致不到1/3的人无法参与转系，但转系人数降低了1/2以上。
     - 隐瞒报名人数导致信息不对称，学生只能凭民间信息和竞争关系做决策，浪费资源。
   - 建议：
     - 公开往年报录情况，让学生有参考，避免盲投博弈和新的内卷模式。

## 转专业硬件要求

   1. <span style = "font-weight:bold">成绩</span>：
      - 成绩是考量因素之一，具有公平性。
      - 每年GPA要求可能不同，一般来说，3.7以上为中高水平。
   2. <span style = "font-weight:bold">课程</span>：
      - 部分院系对转入学生的课程要求较高，可能会安排降级（如交叉信息院、医学实验班）。
      - 提前修读相关课程有助于减轻转入后的负担。
   3. <span style = "font-weight:bold">其他</span>：
      - 高考成绩可能作为参考，但具体作用不详。

## 转专业软件要求

   1. <span style = "font-weight:bold">面试</span>：
      - 面试结果客观，通过面试意味着认可。
      - 面试员包括院系领导、核心课程制定者、教务处老师等。
   2. <span style = "font-weight:bold">兴趣爱好</span>：
      - 大学生应具备正常的兴趣爱好，综合素质全面发展是大学生的要求。

## 转专业后的考虑

   1. <span style = "font-weight:bold">课程认定</span>：
      - 课程认定旨在避免重复学习，许多课程可以相互替代。
      - 常见替代课程如：微积分A与微积分B、数学分析与微积分等。
   2. <span style = "font-weight:bold">学籍手续</span>：
      - 听从辅导员通知，交学籍卡等手续不繁琐。
   3. <span style = "font-weight:bold">选课、小学期</span>：
      - 转入后与新院系一起选课，小学期需要提前打好基础。
   4. <span style = "font-weight:bold">补课程</span>：
      - 毕业前均可补课，高年级可上低年级课程。
      - 提前规划，确保大三小学期结束前完成所有课程。
   5. <span style = "font-weight:bold">科研、社工</span>：
      - 各院系安排不同，视情况而定。

## 常见误区

   1. <span style = "font-weight:bold">成绩与转专业成功率</span>：
      - 不是成绩越好、转入转出院系越相近，成功率越高。
      - 录取考虑多方面因素，不仅是成绩。
   2. <span style = "font-weight:bold">信息匮乏与盲投博弈</span>：
      - 信息不对称导致学生只能凭借民间信息决策，浪费资源。
      - 建议公开往年报录情况，避免盲投博弈。

## 其他注意事项

   1. <span style = "font-weight:bold">转专业的动机</span>：
      - 确定转专业动机是否明确，了解新院系的学习氛围和要求。
      - 避免盲目跟风转专业，慎重考虑个人兴趣和职业发展。
   2. <span style = "font-weight:bold">沟通与了解</span>：
      - 多与导师、学长学姐沟通，了解转专业后的具体安排。
      - 提前准备，避免临时抱佛脚。

## 和转专业有关的一些学校规定

   <span style = "font-weight:bold">第三十三条</span>

   - <span style = "font-weight:bold">申请条件</span>：学生在学习期间对其他专业有兴趣和专长的，可以在一年级或者二年级时按照学校有关规定申请转专业。
   - <span style = "font-weight:bold">限制条件</span>：以特殊招生形式录取的学生，国家有相关规定或者录取前与学校有明确约定的，不得转专业。

   <span style = "font-weight:bold">第三十四条</span>

   - <span style = "font-weight:bold">组织时间</span>：学校每学年组织一次学生转专业工作，统一安排在春季学期进行。
   - <span style = "font-weight:bold">工作方案</span>：转专业工作方案由院系具体制定，报教务处审核备案。
   - <span style = "font-weight:bold">公示名单</span>：学校统一对各院系拟接收转专业学生名单进行公示。

  <span style = "font-weight:bold">第三十五条</span>

   - <span style = "font-weight:bold">课程认定</span>：院系对转专业学生转入前所修课程进行认定。
   - <span style = "font-weight:bold">毕业资格</span>：转专业学生达到转入专业培养方案要求方能取得毕业资格。
   - <span style = "font-weight:bold">延长学习时间</span>：因转专业需要延长学习时间的，应当按照学校有关规定办理手续。

   <span style = "font-weight:bold">第三十七条</span>

   - <span style = "font-weight:bold">学习安排</span>：学生转专业在获学校批准前，应当照常参加所在院系学习。
