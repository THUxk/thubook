# 宿舍介绍

宿舍主要分为紫荆公寓和南区。校外还有博士生居住的双清公寓和红杉公寓等。



## 紫荆公寓

<span style="font-weight:bold">位置：</span>[学校北侧](https://surl.amap.com/hCvotuU1o8Cr)

<span style="font-weight:bold">布局：</span>分为AB间，共用中厅。每间宿舍可住4人，采用“上床下桌”的双层家具，在高层床铺下设有书桌、书架、衣柜及凳子，每间寝室配有洗漱架及阳台。

![sushe_1](..\assets\sushe_1.png)



<span style="font-weight:bold">数据：</span>

床尺寸：200cm*90cm

床与屋顶之间的距离：130cm

床护栏高度：30cm



<span style="font-weight:bold">楼内设施：</span>

一般为6层，新生入住上个毕业年级的宿舍。

<span style="font-weight:bold">无电梯</span>，每个房间内有<span style="font-weight:bold">空调</span>。每层楼有<span style="font-weight:bold">卫生间、洗漱间、淋浴间</span>

<span style="font-weight:bold">热水</span>供应时间为每天6:00-24:00

每隔一层有<span style="font-weight:bold">公共自助洗衣房</span>，每次扫码洗衣，按次付费，平均每房有5-6台洗衣机。

门禁处配有<span style="font-weight:bold">AED除颤仪</span>



<span style="font-weight:bold">宿舍周边：</span>

一层为停自行车，期间夹在24小时自助贩卖机。

近紫荆食堂，桃李食堂，紫操，C楼。

部分楼下有修车铺，打印店，干洗店，小卖部。



## 南区

<span style="font-weight:bold">位置：</span>相对于紫荆公寓的北，在偏南位置，整体位置在学校中部偏北。[南区宿舍](https://surl.amap.com/6JP0xw5O0qx)

<span style="font-weight:bold">布局：</span>4人间，上床下桌，无中厅。上下床为楼梯。配有鞋柜，桌面镜等。

![sushe_2](..\assets\sushe_2.jpg)

![sushe_3](..\assets\sushe_3.jpg)

<span style="font-weight:bold">数据：</span>

床铺尺寸：228*100（cm）

床垫尺寸：200*95（cm）

床与屋顶之间的距离：100（cm）

注意：南区宿舍不同楼结构不完全相同，床铺尺寸可能有一定差距，平均在200*90左右

<span style="font-weight:bold">楼内设施：</span>

楼内配有<span style="font-weight:bold">卫生间，洗漱间，淋浴间，公共洗衣机，洗鞋机，烘干机</span>

一楼有<span style="font-weight:bold">自动售货机</span>

<span style="font-weight:bold">宿舍周边：</span>

近文图，东操，清芬食堂。

楼下有健身房，自习室，奶茶店，干洗店，天猫超市，理发店等，生活设施完善。
