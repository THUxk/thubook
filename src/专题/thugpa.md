# 清华GPA

由于清华的成绩记载改革，当前清华已经不存在百分制的分数。以下表格仅供参考，实际百分制分数与每门课绩点的对应关系由授课老师自行决定，或可能全过程不存在百分制分数。

表中“百分制范围”系指在老版本（2015年）成绩管理规定中给出的百分成绩到等级的映射；“对应百分制数值”系指适用于在改革过渡时期（15-18年）入学的学生等级到百分成绩的映射。均仅供参考。

| 等级 | 绩点 | 百分制范围 | 对应百分制数值 |
| --- | --- | --- | --- |
| A+ | 4.0 | 95-100 | 100 |
| A | 4.0 | 95-100 | 98 |
| A- | 4.0 | 90-94 | 92 |
| B+ | 3.6 | 85-89 | 87 |
| B | 3.3 | 80-84 | 82 |
| B- | 3.0 | 77-79 | 78 |
| C+ | 2.6 | 73-76 | 75 |
| C | 2.3 | 70-72 | 71 |
| C- | 2.0 | 67-69 | 68 |
| D+ | 1.6 | 63-66 | 65 |
| D | 1.3 | 60-62 | 61 |
| F | 0 | 0-59 | 0 |

GPA计算公式：GPA = (每门计入GPA的课绩点×学分的乘积之和) ÷ (计入GPA的总学分)，**四舍五入保留一位小数记载**

其他不计入GPA的等级：

**P(pass)：通过**

部分课程计入学分但不计入GPA，成绩单中只记录P/F，这些课又叫pf课，通常比较抢手。

一个学期亦可以选择一门“课程属性”（培养方案中的属性）为任选的课程手动计P/F，也不计入GPA。

**W(withdrew)：退课**

在退课阶段（通常上了不到半学期）将课程退掉不上了，记录W，补退选阶段退课的（通常为开学第一周和第二周），不记录W。

**I(Incomplete)：未完成**

在课程考核期间因身心疾病等特殊情况不能参加考核环节，提出申请，经教学主管部门批准后备案记载。

在学校规定期间内完成考核后，登载考核成绩，并取消原“I”记录。

**Ex(exempted)：免修**

通过教务批准免修的课，学分计入，但是不计入GPA。
