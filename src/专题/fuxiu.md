# 辅修专业设置

- <span style = "font-weight:bold">2020年起调整</span>：辅修专业改为辅修学位修读，满足要求者可申请辅修学位。
- <span style = "font-weight:bold">辅修专业数量</span>：共有39个本科专业开放辅修，全部为本科专业目录中的专业。
- <span style = "font-weight:bold">培养要求</span>：一般要求30学分左右，以课程修读为主，部分专业有综合类设计或实践环节。

## 学生网上申请辅修学位方法

1. <span style = "font-weight:bold">登录门户</span>：
   - 登录info信息门户 -> 学习 -> 快捷导航 -> 公告，点击下面的二级菜单“申请辅修学位”。
2. <span style = "font-weight:bold">新增申请</span>：
   - <span style = "font-weight:bold">选择辅修培养方案</span>：选择相应年份的辅修培养方案、辅修学位院系、辅修学位专业。
   - <span style = "font-weight:bold">填写联系方式</span>：填写个人联系电话及E-mail。
   - 辅修课程认定：
     - 点击【确定&下一步】进入辅修课程认定界面。
     - 勾选需认定的辅修学位课程，点击右上方【认定辅修课】按钮，已认定辅修学位课程的辅修标志将置为“是”。
   - 核实认定情况：
     - 点击【查看辅修培养方案完成情况】、【查看主修培养方案完成情况】进一步核实课程认定情况。
     - 注意应优先保证主修可以正常毕业。
   - <span style = "font-weight:bold">提交申请</span>：确认后点击【提交申请】完成辅修学位申请。
3. <span style = "font-weight:bold">注意事项</span>：
   - 请务必在规定时间内提交申请，以最终提交的名单为准，逾期不予受理。

## 报名须知

- 报名条件：

  - 辅修专业与主修专业应属于不同专业类（专业代码前四位不同,[专业代码查询]( http://announce.cic.tsinghua.edu.cn/node/26817)）。
  - 符合辅修专业培养方案中的限制条件。

- 报名方式：

  - 自主修读：根据辅修培养方案和课程目录自主修读课程，满足要求后申请辅修学位。
  - 院系审核：部分专业需要提交辅修报名申请，经审核通过后按辅修教学安排进行修读。

- 本科辅修学位专业培养方案查看路径：

  info信息门户首页【教务公告】右侧“教学门户”—办事流程—学生相关—辅修学位—本科辅修专业培养方案

## 选课要求

- <span style = "font-weight:bold">选课时间</span>：辅修课程与主修课程选课同时进行。

- <span style = "font-weight:bold">课程重复</span>：辅修课程与主修课程重复时，经辅修专业院系批准，另选其他课程。

- <span style = "font-weight:bold">成绩单显示</span>：辅修课程在修读过程中以“任选”属性显示在主修成绩单上，只有在通过辅修学位审核后才标注为“辅修”。

## 辅修学位获得要求

- <span style = "font-weight:bold">申请辅修学位</span>：完成辅修专业培养要求的学生，在主修专业毕业学期向辅修专业院系提交辅修学位授予申请。

- <span style = "font-weight:bold">未完成辅修要求</span>：主修专业毕业时未完成辅修要求，所修课程计入主修专业成绩单，不可补修。

## 其他重要提示

- 本科辅修学位专业培养方案详见：[本科辅修专业培养方案](http://announce.cic.tsinghua.edu.cn/node/26945)

- <span style = "font-weight:bold">建议开始时间</span>：大二开始修读辅修较为合适。
- <span style = "font-weight:bold">转为辅修学位</span>：符合要求的旧辅修、二学位学生可申请转为辅修学位修读。
- <span style = "font-weight:bold">课程证书项目</span>：停开的特色辅修专业转为课程证书项目。
- <span style = "font-weight:bold">中途退出</span>：如需退出辅修，请咨询辅修专业院系教学办。
- <span style = "font-weight:bold">未来调整</span>：每年接受辅修学位修读的专业可能调整，请关注公告。
- <span style = "font-weight:bold">课程认定</span>：报名前已经修读的课程，在辅修专业毕业资格审查时进行认定。
