# 经济资助及勤工助学

## 资助项目

### 入学前

<span style="font-weight:bold">入学困难补助</span>

- 家庭经济特别困难的学生可申请来校路费及部分生活费补助。按照录取通知书中《致家庭经济困难新生的一封信》说明，与学生资助管理中心办公室联系。

<span style="font-weight:bold">生源地信用助学贷款</span>

- 每人每年最高贷款12000元，用于支付学费和住宿费。学生和家长向户籍所在地的学生资助管理中心或金融机构申请。



### 报到时

<span style="font-weight:bold">绿色通道</span>

- 新生报到时如有缴费困难，可通过报到现场的“绿色通道”申请无息临时借款，用于缴费，完成注册手续。



### 入学后

<span style="font-weight:bold">助学金</span>

- 家庭经济困难学生每年秋季学期可申请，金额为每年3000-16000元。学生需撰写感谢信或参与公益活动。平均每年有3000人获得，平均金额8000元。

<span style="font-weight:bold">勤工助学</span>

- 大一入学后即可申请校设勤工助学岗位，每小时报酬25-50元，帮助学生减轻经济负担，锻炼能力。

<span style="font-weight:bold">困难补助</span>

- 包括临时困难补助和各类专项补助，如大病紧急救助、新生教材、理发、交通补助等。

<span style="font-weight:bold">海外交流“鸿雁计划”</span>

- 家庭经济困难学生获得学校学期交换或海外研修机会，可申请国际旅费和生活费支持。



### 毕业后

<span style="font-weight:bold">学费补偿或助学贷款代偿</span>

- 在校期间应征入伍或毕业后选择去基层就业的学生可申请学费补偿或助学贷款代偿。
