# 新生骨干

<p style="font-weight:bold">核心：学生工作，班委，社工</p>

[社工](../words.md#社工)

每年开学前会招募一些新生提前报道，参加新生骨干培训。

主要目的是：

1.为开学后的学生工作提前准备人才。比如学生会，班委竞选等。

2.提前熟悉学校，在正式报道时协助其他新生报道，提高报道效率。

<br/>


<p style="font-weight:bold">新生骨干Q&A</p>

* Q：新生骨干会比正常同学早几天报道？<br/>
  A：一般是3-4天<br/>
  
* Q：新生骨干通过率如何？什么背景的同学更容易通过？<br/>
  A：通过主要看辅导员面试结果，表达出自己对参与学生工作的意愿即可<br/>
  
* Q：新生骨干在提前报道期间都有哪些活动？<br/>
  A：新生骨干会按照院系组成不同班级，有各种团建活动和培训，培训主要是关于学生工作的各种技巧。最后有一个班级风采展示，一个班的同学一起排一个节目。其余的还有参观校园、定向越野、集体观影、集中讲座、专项工作坊与交流互动等活动<br/>
  
* Q：新生骨干会提前住到自己宿舍还是集中住在别处？<br/>
  A：提前住到自己宿舍<br/>
  
* Q：参加新生骨干有什么好处？<br/>
  A：好处大概有：
  + 提示升学生工作的技能，对后面竞选班委，参与其他社工有好处。
  + 可以和骨干同学结下深厚的友谊，清华的第一波朋友。
  + 一群人在短时间内迅速熟悉然后一起做很多活动，是一段难忘的回忆
  + 可能是你大学期间接触女生最频繁的时间（有人在骨干的四天内脱单
  + 提前熟悉学校，参与开学迎新，被同学当做学长。
