# 食堂介绍

官方数据为7个学生食堂、9个教室食堂以及10家特色餐厅。

## 桃李园

<span style="font-weight:bold">位置：</span>[紫荆公寓北侧](https://surl.amap.com/5ATaveX4eQS)

<span style="font-weight:bold">介绍：</span>宿舍区食堂，上下4层。一层为风味小吃，二层为自选，三层是云南菜。负一楼为清青休闲餐厅

<span style="font-weight:bold">营业时间：</span>

| 楼层 | 营业时间 |

| 二层 | 午餐 11:00 - 13:00<br/>晚餐 17:00 - 19:00 |

## 紫荆园

<span style="font-weight:bold">位置：</span>[紫荆公寓北侧](https://surl.amap.com/fopqWOg10en8)

<span style="font-weight:bold">介绍：</span>宿舍区食堂，各层都有不错的美食。上下五层，一层为广东，东南亚风味小吃。二层自选快餐，价格实惠。涮羊肉比较有特色。三楼有一些锅仔，酸菜鱼，轻食等。四楼为川香风味。地下是清青披萨。

<span style="font-weight:bold">营业时间：</span>

| 楼层 | 营业时间 |
| --- | --- |
| 一层 | 早餐 6:30 - 9:00<br/>午餐 11:00 - 13:00<br/>晚餐 17:00 - 19:00 |
| 二层-四层 | 午餐 11:00 - 13:00<br/>晚餐 17:00 - 19:00 |

## 玉树

<img src="/assets/shit_7.png" alt="shit_7" style="zoom:50%;" />

<span style="font-weight:bold">位置：</span>[东北角，12号楼东侧，8号楼南侧](https://surl.amap.com/a0hgmlSR54b)

<span style="font-weight:bold">介绍：</span>一层为点菜，二楼是自选套餐，价格小贵，有夜宵

<span style="font-weight:bold">营业时间：</span>

| 楼层 | 营业时间 |
| --- | --- |
| 二层 | 午餐 11:00 - 14:30<br/>晚餐 17:00 - 19:30<br/>夜宵 19:30 - 22:30 |

<span style="font-weight:bold">测评：</span>

+ 关于玉树园食堂二楼的测评
    - <span style="font-weight:bold">进入方法：</span>从食堂左侧的一个螺旋楼梯进入，不要直接去一楼
    - <span style="font-weight:bold">价格：</span>高，正餐15\~30元，整体消费20\~40元。提供夜宵但没去吃过。
    - <span style="font-weight:bold">环境：</span>主要分两部分，北侧类似传统食堂，南侧偏向暖色调，装修更精致，有四人小隔间（可能刷新情侣），也有独立的桌子。建议就餐人数1\~4人。
    - <span style="font-weight:bold">食物：</span>有偏向韩日式风格的套餐。套餐一般由一大盘菜，一碗饭，一碗汤和一小碟泡菜组成。量不是很多，但能吃饱。也有单个菜的盖饭。味道普遍偏甜鲜，给的肉比较多（卖这个价钱当然给得多）。个人感觉大部分吃起来不错。
