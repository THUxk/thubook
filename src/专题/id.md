# 班号与学号

## 班号

班号的组成由：

专业简称 + 入学年份某位数字 + 班级序号组成。

例如，小乐在2024年进入电子工程专业就读，电子信息专业一共5个班，小乐在2班。电子工程专业在清华的简称是“无”，所以小乐的班号是 无42 

[清华专业简称](https://thubook.help/admin/#/collections/topics/entries/f9699c1ecc74)

## 学号

学号通常由 4位入学年份 + 2位类别码+4位id一共10位。

通常本科生类别码为01

例如2022年入学的小李，学号可能是2022010376

### 学号类别码的含义

#### 本科生

01：普通本科生

03：临床医学专业（协和）

04：暑期学生

05：双培计划

08：留学生

11：交换生

#### 硕士生

21：学历教育硕士生

22：非学历教育（工程、MBA、MPA等）

27：港澳台学生

28：留学生

29：访问生

#### 博士生

31：博士研究生

37：港澳台学生

38：留学生

39：访问生
