# 奖学金

## 考核与申请方式

院系级：通常在<span style="font-weight:bold">秋季开学</span>辅导员会在年级群里通知，也可能通知给各班学委，班长，负责。需填写奖学金申请表，通过审核后获取。综合优秀奖学金通常需要进行答辩。

全校级：面向全校的教学金计划，通常由辅导员转发，时间不定，比如"好读书奖学金"之类。

注：每年度的奖学金<span style="font-weight:bold">只和上一年度的表现有关</span>，与之前的无关。例如小明大一表现很差（全系倒数第一，挂科等等）。但是大二学年是全系第一，依然可以在大三开学申请奖学金，并很有可能获取。



## 奖学金类别

### 综合优秀

通常符合2个以上单项，或gpa前20%申请。



<span style="font-weight:bold">国家奖学金</span>

- 设立于2002年，奖励额度为0.8万元/人。

<span style="font-weight:bold">蒋南翔奖学金</span>

- 设立于1989年，纪念蒋南翔校长，奖励全面发展的优秀本科生，奖励额度为2万元/人。

<span style="font-weight:bold">一二·九奖学金</span>

- 由校友张宗植学长于1987年捐资设立，鼓励青年师生，奖励额度为2万元/人。

<span style="font-weight:bold">王大中奖学金</span>

- 设立于2021年，由王大中院士、高祖瑛教授伉俪捐赠，奖励额度为2万元/人。

<span style="font-weight:bold">清华之友奖学金</span>

- 由校友、企事业或社会人士出资设立，用于奖励综合素质突出的学生。



### 单项奖

学业优秀，文艺优秀，体育优秀，志愿公益优秀，社会实践优秀，社会工作优秀，科技创新优秀。

单项奖学金学业优秀人数最多，其余的只表彰年级里最突出的几人（通常不超过3人）

<span style="font-weight:bold">学业优秀奖：</span> 上一学年GPA前30%基本申请都可以拿到，奖学金在3-5k不等。

<span style="font-weight:bold">社会工作优秀：</span> 与成绩无关，只要参与过社会工作，如班委，或学生会里任职，都可以申请，奖金1-3k。

<span style="font-weight:bold">科创优秀奖：</span>   有科研成绩的可以申，科创比赛成绩，paper等等，奖金2k左右。

<span style="font-weight:bold">志愿公益：</span> 社会实践优秀: 奖金1k左右

<span style="font-weight:bold">文艺，体育：</span> 学生节主持人，马杯拿奖等。1-3k。



## 其他奖学金

<span style="font-weight:bold">中国政府奖学金</span>

- 资助学费、住宿费、生活费和综合医疗保险费等，申请时间一般为11月至4月。通过中国驻国际学生所在国大使馆或总领事馆申请。

<span style="font-weight:bold">北京市外国留学生奖学金</span>

- 分全额学费和部分学费两类，需逐年申请，申请时间一般为3-4月。

<span style="font-weight:bold">教育部“优秀来华留学生奖学金”</span>

- 奖励在华国际学生，国际本科生获奖者一次性奖励人民币1.8万元。

<span style="font-weight:bold">港澳及华侨学生奖学金</span>

- 奖学金分四个等级，特等奖8000元/年，一等奖6000元/年，二等奖5000元/年，三等奖4000元/年。

<span style="font-weight:bold">台湾学生奖学金</span>

- 奖学金分四个等级，特等奖8000元/年，一等奖6000元/年，二等奖5000元/年，三等奖4000元/年。

<span style="font-weight:bold">唐立新奖学金</span>
- 一般大三评定，一经获取直到学位（硕士，博士均可）完成，每年获得1w。

还有更多奖学金，请关注相关公众号推送，通知等。

## 研究生奖学金
* 综奖：5000,1w两档
* 国家奖学金：3w
* 未来学者奖学金：入学时评定，每年2w
* 其他院系奖学金


## 奖学金到账时间
大部分奖学金，竞赛奖金，会在12月31日到账。但也有可能随机时间到账。
