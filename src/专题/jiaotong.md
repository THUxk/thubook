## 校园交通车

<img src="../assets/jt_5.png" alt="图片" style="zoom:50%;" />

清华证件可免费乘车，可以在站点等候，也可以招手上车、就近下车。

<span style="font-weight:bold">运行时间：</span>

+ 工作日：7:20-18:00
+ 节假日：8:30-17:40

<span style="font-weight:bold">校园巴士线路：</span>

+ 西校门发车，分内环线、外环线和学生专线，覆盖学生住宿区、教学科研区和家属区。

+ <span style="font-weight:bold">外环：</span>

  <span style="font-weight:bold">运行时间</span>：工作日7:20-18:00，星期六、日及法定节假日8:30-17:30，寒暑假运行以公告为准。

  <span style="font-weight:bold">始发地点</span>：西校门

  <span style="font-weight:bold">运行模式</span>：每10分钟发车一次，同向行驶间隔20分钟发车一次。双方向交替发车。

  <span style="font-weight:bold">行车路线</span>：西校门—游泳池—问讯处—老年活动中心—幼儿园—李兆基科技大楼—主校门—美术学院—综合体育馆—游泳馆—紫荆操场—紫荆公寓17号楼—北校门—图书馆—西北校门—校医院—西湖游泳池—西校门

  

+ <span style="font-weight:bold">内环：</span>

  <span style="font-weight:bold">运行时间</span>：工作日7:40-17:25，星期六、日、法定节假日停运、寒暑假另行通知。

  <span style="font-weight:bold">始发地点</span>：西校门

  <span style="font-weight:bold">运行模式</span>：每15分钟发车一次，同向行驶间隔30分钟发车一次。双方向交替发车。

  <span style="font-weight:bold">行车路线</span>：西校门—游泳池—问讯处—二校门—新清华学堂—李兆基科技大楼—主校门—美术学院—主楼—新清华学堂—二校门—问讯处—西湖游泳池—西校门

具体线路和发车时间请查看<span style="font-weight:bold">清华校园巴士</span>微信小程序。

程序内可以看巴士路线，方便在校内更好出行，以及会提供不同巴士环路的具体信息，可以熟悉巴士路线，以及校园巴士的运行时间，选择停靠点也能为你在清华园中出行更加便利。

## 校内出行

+ <span style="font-weight:bold">自行车是校内最主要、最便捷的通勤方式</span>

  以下是校园内自行车铺部分信息

  | 地址                         |              营业时间              |
  | ---------------------------- | :--------------------------------: |
  | 紫荆3号楼三单元后            |             9:00-19:00             |
  | 紫荆5号楼六单元后            |             9:00-21:00             |
  | 紫荆9号楼三单元后            |             9:00-20:00             |
  | 紫荆10号楼二单元后           |             8:00-19:00             |
  | 紫荆11号楼（兼修电脑、手机） |             9:00-23:00             |
  | 南区1号楼北                  |             9:00-19:00             |
  | 南区15号楼北（共3个摊位）    | 7:30-21:30；8:00-20:00；9:00-21:00 |

+ <span style="font-weight:bold">电动车</span>

  关于电动车出行，请同学们了解以下规定：

  1. <span style="font-weight:bold">电动车管理通知</span>：
     - 自2021年11月1日起，未悬挂正规号牌或临时标识的电动自行车禁止进入校园。无牌或悬挂临时标识的电动车停放在校园内将被贴条并处理。
     - 校内限速15公里/小时，需避让行人和自行车，禁止鸣笛、使用手机，建议佩戴头盔。
     - 各单位、楼宇物业禁止电动车在办公场所充电，电动车及电池不得进入教学、科研、办公场所和学生公寓。
  2. <span style="font-weight:bold">公寓管理办法</span>：
     - 学生公寓禁止携带电动车电池，禁止停放电动车或为电动车充电。
  3. <span style="font-weight:bold">电子标签管理办法</span>：
     - 自2019年4月30日后，不再新办电子标签。标签只能本人、本车使用，不得转让或转移位置。
     - 自2019年5月1日起，未加装电子标签的电动自行车禁止在学生生活区行驶、停放。
     - 2021年11月1日起，悬挂临时标识的电动自行车不得上道路行驶，相应电子标签失效。学生毕业离校时，电子标签自动注销。
